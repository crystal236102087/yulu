# 余录 · 读书摘录

一款中国古典风格的读书摘录 PWA 应用：宣纸底色、毛笔书法、朱砂印章。

## 功能

- 📜 **摘录记录**：抄录原文、出处、理解、联想、笔记
- 🔍 **相似佳句**：理解句意自动搜罗 2-3 句相近佳句（古文 / 英谚）
- 📚 **书目管理**：书脊墙、分类、在读/读完
- 🍃 **今日佳句**：结合节气、天气、时下热点，每天推荐应景佳句；平时优先论语 / 孟子 / 道德经
- ☁️ **云同步**：数据保存在 GitHub 私有仓库（`yulu-sync`），跨设备同步、永久可靠
- 📱 **PWA**：可安装到手机主屏幕，离线可用

## 使用

直接打开 [GitHub Pages](https://crystal236102087.github.io/yulu/) 即可使用。

iOS：Safari 打开 → 分享 → 添加到主屏幕。
Android：Chrome 打开 → 安装应用。

## 技术栈

单文件 HTML + Tailwind CSS + 原生 JS + Service Worker。
